Le tableau de bord de mes projets

Archive du 18 novembre 2026 — 6 projets · 25 / 41 étapes (61 %) · 13 recherches de veille.

Ce dossier contient tout : le site, ses données, ses images, et ce mode d'emploi. Il fonctionne sans Internet, sans compte, sans installation. Tu peux le copier sur une clé, l'envoyer par mail, ou le garder six mois dans un coin — il s'ouvrira encore.

1. Ouvrir le tableau de bord

1
Décompresse le dossier Si l'archive est un .zip : clic droit → « Extraire tout » (Windows) ou double-clic (Mac). Il faut travailler dans le dossier extrait, pas dans le zip.
2
Ouvre COMMENCER-ICI.html Double-clic dessus. Il s'ouvre dans ton navigateur.
3
Clique sur « Ouvrir le tableau de bord » Tu arrives sur la page d'accueil de présentation, puis sur le tableau lui-même.
Ça s'ouvre dans un éditeur de texte ? Clic droit sur le fichier → Ouvrir avec → choisis ton navigateur (Firefox, Chrome, Edge, Safari). Sur Mac, Ouvrir avec → Safari. Si le navigateur demande « autoriser les scripts », accepte : sans eux, rien ne s'anime.

Les adresses qui ouvrent directement un projet

À la fin de l'adresse dans la barre du navigateur, on peut ajouter #proj-velo, #proj-poche, #proj-sites, #proj-maquette, #proj-notes, #proj-ia-decouverte. La page s'ouvre alors directement sur ce projet, étapes dépliées.

Ce qui change et ce qui ne change pas

  • Les coches sont gardées par appareil, dans le navigateur. Deux appareils ne se parlent pas.
  • Rien n'est publié tant qu'on n'appuie pas sur « Enregistrer sur GitHub » — et ce bouton a besoin d'une clé qui n'est pas dans cette archive. Impossible donc de casser le site par erreur.
  • Fermer l'onglet ne perd rien ; vider les données du navigateur, si.

3. Envoyer ou partager

  • Par mail : joindre le .zip. Attention, beaucoup de boîtes refusent au-delà de 20–25 Mo ; celle-ci pèse environ 1,5 Mo, ça passe.
  • Par clé USB : copier le dossier extrait tel quel.
  • Le lien en ligne, si le site est encore publié : https://franceinfo771-prog.github.io/tableau_de_bord/

4. Le retrouver dans six mois, ou dans deux ans

Il n'y a rien à mettre à jour, rien à maintenir : les fichiers HTML et les images sont des formats que les navigateurs liront encore dans vingt ans. Trois précautions suffisent :

  1. Garder l'archive en double : une copie sur l'ordinateur, une sur une clé ou un disque externe. C'est la seule vraie fragilité — pas le format, la perte du fichier.
  2. Ne pas la modifier à la main. Si un chiffre doit changer, il se change dans le tableau puis « Exporter », ou avec les fichiers de technique/ (voir plus bas).
  3. Se souvenir du nom : le tableau s'appelle tableau de bord — mes projets, et il vit dans le dépôt GitHub franceinfo771-prog/tableau_de_bord.

5. Pour plus tard : reprendre le site

Le dossier technique/ contient le code source, les données (projets.json), les consignes de travail (ASSISTANT.md), l'état des lieux (ETAT.md) et les scripts de vérification. Deux manières de repartir :

  • Sans rien installer : demander à un assistant (Arena ou autre) de reprendre le dossier. Colle ceci comme premier message : « Voici mon tableau de bord, un site en une page. Lis ASSISTANT.md puis ETAT.md, et aide-moi à le faire évoluer. »
  • En ligne : ouvrir le dépôt GitHub franceinfo771-prog/tableau_de_bord, créer une branche, proposer une modification, puis fusionner. Le site se redéploie seul en une minute.

Les commandes de vérification, si tu es à l'aise avec le terminal, sont dans technique/README.md. Elles ont servi avant chaque mise en ligne (58 vérifications automatiques au total : rendu, liens, page d'accueil, bouton de copie).

Confidentialité. La page ne contient aucun script de mesure, aucun cookie, aucune police ni image distante. Ouverte depuis ce dossier, elle ne contacte aucun serveur. Le site en ligne, lui, est hébergé par GitHub Pages, qui garde une trace technique des visites dans ses journaux — et le site demande aux moteurs de recherche de ne pas l'indexer (robots.txt + noindex).
